# Spotify Music Popularity Analysis
This project analyzes Spotify's 2023 song dataset to identify factors associated with streaming success.The analysis was performed using Google Sheets, data cleaning techniques,and Pivot Tables.
## Dataset
Source: Spotify 2023 Songs Dataset

Records Analyzed: 953 Songs

### Features Included:

- Streams
- BPM
- Release Month
- Spotify Playlist Counts
- Apple PLaylist Counts
- Key
- Danceability
- Energy
- Valence

## Questions

1. Does BPM affect streams?
2. Does release month affect streaming success?
3. Does playlist placement affect streams?
4. Which is better with streams, spotify playlist placement or apple playlist placement?

## Key Findings

1. BPM showed little evidence of a strong relationship with stream counts.

2. Release month did not appear to consistently impact streaming success.

3. Songs with higher playlist placement generally received more streams.

4. Spotify playlist placement showed a better relationship with streams than Apple Music playlist placement in this dataset.

 ## Tools Used

   - Google Sheets
   - Pivot Tables
   - Data Cleaning
   - Basic Data Analysis

## Conclusion

Among the factors analyzed, playlist placement showed the largest differences in average stream counts. Songs with higher playlist exposure consistently received more streams, particularly on Spotify. BPM and release month also showed cohesive results with streaming performance, though the differences were less noticeable.

It is important to state that the data within this analysis shows the relationships within the dataset and does not prove cause and effect. Factors such as artists popularity, marketing, and platform specific differences may also help streaming performance. The results suggest that playlist exposure is one of the strongest factors associated with higher stream counts among the songs analyzed.
